# Fraud & AML Detection with Machine Learning

Portfolio project demonstrating fraud detection on transaction data: gradient boosting
for supervised classification, isolation forests for unsupervised anomaly detection,
and SHAP for explainable predictions.

> **Data note:** All data in this project is **synthetic**, generated by
> `src/generate_data.py`. No real customer data, employer data, or production
> code is used. This is a personal project built to demonstrate techniques
> commonly used in fraud and anti-money-laundering (AML) work.

## Problem

Card fraud is rare (around 2% of transactions here) but expensive. A useful model
must catch as much fraud as possible (high recall) without declining too many
legitimate transactions (precision), and its decisions must be explainable to
analysts and reviewers.

## Approach

1. **Synthetic data generation** — 50,000 transactions with realistic fields:
   amount, hour, merchant category, device type, account age, distance from home
   location, 24h transaction velocity, new-device and international flags.
   Fraud is driven by interpretable risk signals (large amount, odd hour, new
   device, distant location, high velocity) plus noise, so models must learn
   signal rather than memorize a rule.
2. **Supervised model** — XGBoost with `scale_pos_weight` to handle the
   98/2 class imbalance, one-hot encoded categoricals, stratified split.
3. **Unsupervised baseline** — Isolation Forest on numeric features, scored
   against the same test set for comparison.
4. **Explainability** — SHAP values on the XGBoost model to rank the features
   driving fraud predictions (optional; the script runs cleanly without SHAP
   installed).

## Results

Run `python src/train.py` to reproduce metrics on your machine. Expected
behavior on the default seed: XGBoost clearly beats the anomaly baseline on
precision-recall (fraud is signal-driven, not purely outlying), and SHAP ranks
amount, new-device, distance, and velocity among the top drivers.

## How to run

```bash
pip install -r requirements.txt
python src/train.py            # train + evaluate both models, print metrics
python src/generate_data.py    # optional: save a sample CSV to data/
```
